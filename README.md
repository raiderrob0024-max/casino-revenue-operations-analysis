# Casino Revenue & Operations Analysis

## Project Overview
Independent data analytics case study completed for a Data Analyst interview assessment using simulated casino gaming and hospitality data from 2024–2025.

## Tools & Skills
- Microsoft Excel
- XLOOKUP and PivotTables
- Data cleaning and validation
- KPI development
- Year-over-year analysis
- Business intelligence and reporting

## Project Objectives
- Analyze gaming revenue and operational trends
- Identify top-performing slot themes
- Evaluate Baccarat wagering behavior
- Analyze restaurant spending per cover
- Identify high-revenue patrons
- Develop actionable business recommendations

## Analytical Approach
Reviewed and enriched transaction data using calculated fields and XLOOKUP. Identified missing patron IDs, missing location attributes, and zero-cover restaurant transactions. Documented assumptions and applied consistent calculation methods.

## Key Findings
- Gaming activity declined modestly from 2024 to 2025.
- Royal Ruby Reign was the highest-revenue slot theme in the 2025 dataset.
- Average Baccarat wagers and restaurant spending per cover remained relatively stable.
- Anonymous patron activity presented limitations for customer-level analysis.

## Project Deliverables
An Excel analysis workbook and executive-style presentation documenting methodology, findings, and recommendations.

## Data Disclaimer
This project uses simulated data and does not represent actual casino financial performance.
